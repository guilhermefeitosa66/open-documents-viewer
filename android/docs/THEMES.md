# Themes

Source: the shared `libre-apps-themes` folder, **copied** here (never referenced at build time):

- `docs/themes/themes.json`: the palettes, as received.
- `app/src/main/assets/backgrounds/<id>.webp`: the portrait (1080×2400) backgrounds, converted to WebP (quality 80).
- `app/src/main/kotlin/.../ui/theme/ThemeCatalog.kt`: generated by `python3 tools/gen_themes.py`, so no JSON is parsed at startup.

Rules followed (from the themes README): the default is libre-apps following the system light/dark; the
background image appears only on the start screen (recents, empty state, top bar and footer, on
`surface` at 85% opacity); the document area is always the solid `bg` color; the image is decoded
after the first frame, off the main thread, sampled to the screen width and cached; a switch in
Settings turns the image off.

## Roles mapped to existing keys

The shared palette has no key for some roles of this app's highlighter. They reuse existing keys
(no new colors were made up):

| App role | Theme key |
|---|---|
| annotations (`@Composable`), JSON/YAML/.env keys | `syntax.attribute` |
| INI/TOML sections | `syntax.type` |
| literals (`true`, `null`) | `syntax.constant` |
| markdown markers in source view (`#`, `**`, `-`) | `syntax.operator` |
| headings in source view | `markdown.heading` |
| links | `ui.link` |
| code inside markdown source | `syntax.string` |
| current search match | `ui.accent` on `ui.onAccent` (other matches: `ui.searchHit`) |
| line numbers | `ui.textMuted` |
| quote background | `ui.surfaceAlt`, with a `markdown.quoteBar` bar |

## Open points reported to the theme owner

- `themes.json` names `background` as `backgrounds/svg/<id>.svg`, but the files are
  `<id>-landscape.svg` / `<id>-portrait.svg`.
- Pastel contrast on `bg`: `textMuted` 3.6:1, `onAccent` on `accent` 4.0:1, and several syntax
  colors under 4.5:1 (comment 2.5, string 3.7, number/constant/attribute 3.8, punctuation 3.6).
  Dracula, Kitty and Neon comments are 3.0, 3.8 and 2.8 (their public palettes).
