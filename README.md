# Open Documents Viewer

A fast, offline, read-only document viewer, part of [libre-apps](https://libre-apps.org/open-documents-viewer/).
No ads, no account, no internet, no telemetry.

| Folder | Platform | Stack |
|---|---|---|
| [`android/`](android) | Android 8.0+ | Kotlin, Jetpack Compose |
| [`linux/`](linux) | Linux desktop (AppImage, .deb) | Python, GTK 4, libadwaita |

Both apps share the name, the idea and the libre-apps themes; each one follows its own platform.
Build and test instructions are in each folder's README.

## Releases

Each platform is released on its own, with prefixed tags: `android-vX.Y.Z` (APK) and
`linux-vX.Y.Z` (AppImage and .deb). See the [releases page](https://github.com/guilhermefeitosa66/open-documents-viewer/releases).
